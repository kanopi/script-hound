## retire-jsrepository.json

Vulnerable JavaScript library database from [Retire.js](https://github.com/RetireJS/retire.js)
(`repository/jsrepository-v4.json`), used by `lib/vulndb.mjs` for the `vulnerable-library` rule.

- Snapshot taken: 2026-11-23. Refresh with `make update-vulndb`.
- Kept in the repo so scans work offline (Docker, CI).
